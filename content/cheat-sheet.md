# Cheat Sheet

Quick reference for all key numbers, rules, and strategies.

## Algorithm Multipliers

| Factor | Weight |
|--------|--------|
| Reply vs Like | 27x more weight |
| Block rate penalty | -74x |
| Mute rate penalty | -31x |
| Report rate penalty | -369x |

## Targeting Rules

| Parameter | Value |
|-----------|-------|
| Target follower ratio | 5-20x your count |
| Reply time window | Within 5 minutes |
| Max existing replies on target | < 20 |
| Max hashtags | 0-1 (3+ triggers spam) |
| Link placement | In follow-up reply, not main |

## Volume Guidelines

| Level | Daily Count |
|-------|-------------|
| Sweet spot | 15-20 replies |
| Soft limit | ~50 replies |
| Hard limit | ~500 replies |

## The 70/30 Rule

- **70%** of time on replies
- **30%** of time on original content

## 7 Reply Types

1. Data Reply — Share specific metrics
2. Experience Reply — Personal stories
3. Insight Reply — New perspective
4. Question Reply — Thoughtful questions
5. Contrarian Reply — Respectful disagreement
6. Amplification Reply — Extend their point
7. Resource Reply — Helpful tools/references

## Quality Checklist

- [ ] Concise (1-2 tweets max)
- [ ] Specific (concrete details/data)
- [ ] Value-add (new info or perspective)
- [ ] Standalone (makes sense without context)
- [ ] No self-promotion
- [ ] No engagement bait
